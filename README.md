# 📊 Desafio Criativo: Extraindo Insights do Feedback de Clientes Bancários

## 🚀 Sobre o Projeto
Este repositório contém a solução do **Desafio Criativo** realizado no **Bootcamp Bradesco - GenAI, Dados & Cyber**, promovido pela **Digital Innovation One (DIO)**.  

O desafio tem como objetivo aplicar **engenharia de prompt** para orientar uma IA na análise de **feedbacks de clientes bancários**, transformando comentários em **insights claros, organizados e acionáveis**.

---

## 🎯 Objetivo
Construir um prompt estruturado que permita:
- Classificar feedbacks por **tema, sentimento, urgência e produto citado**.  
- Identificar **padrões, problemas, elogios e oportunidades**.  
- Apontar **evidências nos dados fornecidos**.  
- Sugerir **ações práticas** para equipes de experiência do cliente e canais digitais.  

---

## 📂 Estrutura do Repositório
- `prompt.md` → Arquivo principal com o prompt final.  
- `README.md` → Documento explicativo sobre o desafio e o repositório.  

---

## 🧩 Metodologia
O desafio foi resolvido em três etapas:
1. **Definição da intenção** → O que a IA deve produzir e para quem.  
2. **Adição de contexto e restrições** → Quais dados estão disponíveis e cuidados necessários.  
3. **Unificação e refinamento** → Construção do prompt final, claro e acionável.  

---

## 📋 Prompt Final
O prompt final está disponível no arquivo [`prompt.md`](./prompt.md).  
Ele descreve o papel da IA, os dados a serem analisados, o formato esperado da resposta e as restrições para garantir clareza e segurança.
